# 💡 Notas Zettelkasten

Ideas **atómicas**: una sola idea por nota, escrita con tus palabras, enlazada a otras.
Aquí es donde el segundo cerebro "piensa" y conecta conocimiento.

## Cómo
1. Una idea = una nota.
2. Título = la idea en una frase.
3. Enlaza a notas relacionadas con `[[ ]]`.
4. No jerarquías rígidas: deja que el [[grafo]] emerja.
