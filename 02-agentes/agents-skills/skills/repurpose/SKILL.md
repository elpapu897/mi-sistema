# repurpose

One deep asset becomes a week of content. This is the Content Flywheel: long-form
is the foundation, you deconstruct it into many short forms, distribute per channel.
Default output: **English**.
Reference: multi-channel / flywheel §13, Best of Nine §6, funnel §7–8 in
`../social-content-os/reference/frameworks.md`. Load `../social-content-os/brand.json`.

## Inputs

- The source asset: paste the text, give a file path, or a URL/transcript.
- Target channels (default from brand.json).
- How many pieces to extract (default: a 1-week batch — see below).

## Method

1. **Mine the asset** for its distinct ideas, claims, stories, data points, and
   contrarian takes. Each becomes a potential atomic post. Aim for the strongest
   8–12 nuggets, not every sentence.
2. **Assign a format** to each nugget by what it is:
   - A story or transformation → Reel/Short hook + script, or a carousel.
   - A framework or list → carousel (high dwell time).
   - A sharp opinion or data point → LinkedIn/X text post.
   - A how-to → carousel or thread.
3. **Map funnel stage** for each (Unaware → Conversion) and channel, so the batch
   nurtures across the funnel, not just ToF.
4. **Apply Best of Nine:** pick the 3 strongest formats and note how to recreate
   each 3x (different hook/angle) to find a repeatable winner.
5. **Route, don't write everything inline.** Output is the plan + the seed for each
   piece; offer to run **hook-lab** on the Reel/short ideas, **carousel-builder**
   on the carousel ideas, and **caption-writer** on the text posts.

## Output

A **repurpose sheet** (table): piece # | source nugget | format | channel | funnel
stage | working hook | which skill builds it. Default batch = roughly:

- 2 carousels, 3 short-video hooks+scripts, 3 text posts (IG/LinkedIn/X), 1 thread.

Then a short "build order" recommending which 3 to produce first and why, and the
one-click handoffs to the production skills.
